# kotlin-lotto

## 기능 요구 사항
- [x] 로또 숫자는 1 ~ 45 사이의 숫자로 이루어져있다.
- [ ] 구입 금액을 입력하면, 금액 / 1000 만큼 로또를 발급한다.
- [ ] 구입 금액이 1000원 미만이거나 1000원으로 나누어떨어지지 않으면, 숫자로 반환한다.
- [ ] 발급 가능한 로또 장수를 알려준다.
- [ ] 로또는 1~45 사이의 서로 다른 숫자 6개로 구성된다
- [ ] 로또는 로또를 발급해준다.
- [ ] 돈은 계산할 수 있다.
- [ ] 당첨번호와 보너스 번호가 겹치면, 오류로 처리한다.
- [ ] 당첨 번호는 로또가 들어오면 몇개의 번호가 일치하는 지 출력한다.
- [ ] 보너스 번호는 로또와 일치하는 번호가 있는지 알고 있다.
- [ ] 당첨 번호와 보너스 볼을 입력하면, 당첨 통계를 출력해준다.

## 힌트
- 로또 자동 생성은 shuffled()을 활용한다.
- sorted()를 활용해 정렬 가능하다.
- contains()를 활용하면 어떤 값이 존재하는지 유무를 판단할 수 있다.
- 일급 컬렉션을 쓴다.
- 6개의 숫자 값을 가지는 컬렉션을 감싸는 객체를 추가해 구현해 본다.
- 하드 코딩을 하지 않기 위해 상수 값을 사용하면 많은 상수 값이 발생한다. Enum 클래스를 활용해 상수 값을 제거한다. 즉, Enum 클래스를 활용해 일치하는 수를 로또 등수로 변경해 본다.
