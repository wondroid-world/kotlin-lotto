# kotlin-lotto
- [ ] 로또 구입 금액을 입력한다.
- [ ] 로또 발급 가능한 갯수를 내보낸다.
- [ ] 로또 1장 가격은 1000원이다.
- [ ] 로또 구입 금액에서 로또 발급한 금액은 뺀 잔돈을 내보낸다.
- [X] 로또 번호는 1 ~ 45번 사이의 숫자이다.
- [X] 로또는 6개의 숫자를 가진다.
- [X] 로또 번호는 중복되면 안된다.
- [X] 로또 번호를 발급한다.
- [X] 당첨 번호는 6개의 숫자와 보너스 번호를 가진다.
- [X] 로또 번호 중 보너스 번호가 있는 지 확인한다.
- [ ] 로또 번호 중 당첨 번호가 몇 개있는 지 확인한다.
- [ ] 각각의 로또 번호가 몇 등인지 계산한다.
- [ ] 총 수익률을 계산한다.
